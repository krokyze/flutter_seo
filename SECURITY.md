# Security Policy

## Supported Versions

Only the latest version published on pub.dev receives security updates.

## Reporting a Vulnerability

Report privately via GitHub's [private vulnerability reporting](https://github.com/krokyze/flutter_seo/security/advisories/new). Please do not open a public issue.

This is a small spare-time project. I aim to acknowledge reports within 14 days, but I can't commit to a fixed timeline for triage or fixes.
